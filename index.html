☁️ 모바일 서명·첨부 Google Drive 설정
개인 구글 계정 드라이브에 학생 가정통신문 서명 이미지를 안전하게 저장하기 위한 설정입니다. 아래 [Apps Script 코드 복사하기] 버튼을 눌러 개인 Google 계정으로 웹 앱을 배포한 뒤 발급된 URL을 붙여넣으세요.

📋 개인 Google Drive 웹 앱 배포 가이드

✅ 최신 Apps Script 코드가 클립보드에 복사되었습니다. 아래 순서대로 개인 Google 계정에 배포해 주세요.
  1. 개인 Google 계정(@gmail.com)으로 script.google.com 로그인 → 새 프로젝트
  2. 복사한 코드 붙여넣기 → 저장 (Ctrl+S)
  3. 우측 상단 배포 → 새 배포 → 유형: 웹 앱 선택
  4. 실행 주체: 나, 액세스 권한: 모든 사용자 선택 후 배포
  5. 생성된 웹 앱 URL(https://script.google.com/macros/s/.../exec)을 입력칸에 붙여넣고 프로필 저장하기 클릭
